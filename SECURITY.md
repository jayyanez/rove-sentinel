# Security reporting

Please report vulnerabilities through this repository's GitHub **Security →
Report a vulnerability** flow when enabled. If that flow is unavailable, open
an issue asking for a private reporting channel without including exploit
details, secrets, or private source code.

Include affected Sentinel version, platform, reproduction steps and impact.
Do not include real provider credentials. The current project has no published
response-time guarantee or independently certified security assurance.

Read [trust and data boundaries](docs/security.md) before enabling review of
external contributions or project build scripts.
